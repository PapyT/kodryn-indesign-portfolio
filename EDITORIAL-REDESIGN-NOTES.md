# Kodryn Editorial Website Redesign (4 Nov 2026)

## Visual principles studied
- DAC Studios: dramatic typographic introduction and a deliberately curated selection rather than immediate catalogue density.
- Actual Source: stripped-back project metadata, clear specifications and archive-first typography.
- Studio Feixen: project taxonomy, work grouped by conceptual practice and playful but controlled layout contrasts.
- Pentagram editorial: distinct discipline and publication pages, oversized imagery, meaningful section narratives, and varied work-grid rhythm.

The design implementation is original; none of the sites' code, branding, case photographs, artwork or wording were copied.

## Information architecture
- Homepage: large editorial hero, eight curated selected case studies with mixed dimensions, six discipline collections, approach and contact.
- Six /disciplines/ routes: 7,7,6,9,4,7 projects with their own introductions and asymmetric imagery.
- /work/: searchable and filterable 40-project alphabetical typographic index, with sticky image preview.
- Forty existing /work/{slug}/ routes: editorial project introductions, approved three-board image viewer, category-aware next/previous.
- PDF: 132-page downloadable Form / Function portfolio remains available.

## Design language
Warm paper, dark charcoal, limited vermilion accents, licensed self-hosted Hanken Grotesk and Instrument Serif, readable labels, responsive layouts. User OS theme respected, reduced motion supported.

## Evidence and boundaries
Every showcased project comes from approved assets in dist/assets/approved-2026; all are explicitly portfolio studies rather than commissioned work. External reference sites informed principles only.
